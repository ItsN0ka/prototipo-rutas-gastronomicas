# Sabores del Norte — React + Vite

Ejecuta `npm install` y luego `npm run dev`. El mapa y las rutas requieren conexión a internet.

- `src/components`: componentes de interfaz, mapa y zonas cercanas.
- `src/data/places.js`: datos de localidades de demostración.
- `src/services/rutas.js`: servicio OSRM y cálculo de cercanía.
- `src/App.jsx`: estado y coordinación de la aplicación.
- `src/style.css`: estilos.

Las ubicaciones son referenciales; confirma la información antes de un uso público. Los tiempos no incluyen tráfico ni paradas.
